# 🌳 Simulador de Árvore 2-3

Projeto interativo para visualização de **Árvores 2-3**, desenvolvido em HTML, CSS e JavaScript. O projeto permite a inserção de valores, realiza o rebalanceamento automático (*split*) dos nós e exibe a hierarquia visualmente na tela.

Metodologia de codigo passado na aula de ED2(projeto focado para estudos/teste de mesa)

---

## 📌 Funcionalidades

- ➕ **Inserção Dinâmica:** Adicione novos números à árvore com atualização imediata da tela.
- ⚡ **Rebalanceamento (Split):** Divisão automática de nós quando atingem o limite de chaves.
- 🎨 **Visualização de Nó:** Representação dos nós no formato `[ Info 1 ][ Info 2 ]`.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
